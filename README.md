# Sadar Spaces

Build a Premium Website for SADAR CONSTRUCTIONS

Create a complete, production-quality website for SADAR CONSTRUCTIONS, a premium residential and commercial construction company.

The website should feel like a high-end architecture studio + luxury construction company, not like a generic local contractor website.

The visual references supplied with this prompt include:

Architectural floor plan
Luxury residential exterior
Modern/classical residential facade
Contemporary multi-level building elevation
Sadar Constructions branding/signage

Use these uploaded images as the primary visual inspiration for the website's design language, photography treatment, architecture portfolio, colors, spacing, and overall premium feel.

Also include a prominent social-media connection to the company's Instagram:
https://www.instagram.com/sadarconstructions/

Do NOT invent company information that has not been supplied. Use editable placeholder content wherever actual information is unavailable.
